# URL Shortener

A modern URL shortener web application built with Next.js.

## Overview

This project lets users create short links and manage them from a simple dashboard.

Core capabilities:
- Create shortened URLs
- Store and manage links per user
- Redirect short links to original URLs

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Drizzle ORM
- PostgreSQL (Neon)
- Clerk (Authentication)
- pnpm

## Development Approach

This project was built using agentic AI development with GitHub Copilot.
